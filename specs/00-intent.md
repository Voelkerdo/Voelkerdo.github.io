# Intent

> Status: approved · Owner: Dominik Völker

## Warum gibt es diese Website?
Personal Branding: Die Website macht Dominik Völker als Person und Fachexperte sichtbar und wiedererkennbar.

**Positionierung:** Fullstack-Entwickler.
- Backend ABAP, Node.js
- Front End SAP UI5, JavaScript, HTML5
- Frameworks: SAP UI5, ABAP RAP, ABAP Programming Model for Fiori, SAP ODATA via SEGW, SAP Adobe Forms
- Andere SAP Erfahrung: User und Berechtigungsmanagement.

Nebenziel: Das Projekt dient als Testfeld für den Spec-Driven-Development-Workflow.

## Für wen ist sie?
- **SAP-Community** – Entwickler, Architekten und Interessierte aus dem SAP-Umfeld
- **Andere Entwickler** – die breitere Developer-Community außerhalb von SAP

## Was sollen Besucher danach denken / tun?
- **Gefühl:** „Wow, coole Website!“ – Besucher sollen staunen. Die Website selbst ist das wichtigste Showcase-Projekt.
- **Handlung:** Besucher schauen auf Dominiks GitHub-Profil vorbei (primärer Call-to-Action).

## Kerninhalte
- Git-Projekte
- Skills
- Werdegang
- Kontakt

## Erfolgskriterien
- Kollegen, Freunde und Familie, denen die Website gezeigt wird, reagieren spontan mit „cool“ / „wow“.
- Die Anzahl der GitHub-Follower steigt.

## Nicht-Ziele (v1)
- Kein CMS
- Kein Backend
- Kein Login
- Keine Mehrsprachigkeit

## Leitplanken
- **Tech-Stack:** React + SAP UI5 Web Components.
- **Gestaltungsprinzip:** UI5 ist das Fundament; der Wow-Effekt entsteht obendrauf (eigenes Theming, Animationen, Inszenierung). Botschaft: „Seht her, was man aus UI5 machen kann.“
- **Sprache der Website:** Englisch.
- **Hosting:** offen – vorerst nur lokale Entwicklung. Entscheidung später.
- **Termin:** keiner.
